# ResearchMind: AI Research Assistant

[![Python](https://img.shields.io/badge/Python-3.10%2B-blue.svg)](https://www.python.org/)
[![RAG](https://img.shields.io/badge/Architecture-RAG-green.svg)](https://github.com/muhammadwaqas1564/ResearchMind)

`ResearchMind` is an AI research assistant that parses, summarizes, and extracts key diagnostic insights from academic papers using LLM orchestration and Retrieval-Augmented Generation (RAG).

---

## Key Features
* **PDF & LaTeX Parsing:** Extracts structured text, figures, equations, and tables from academic preprints.
* **RAG Vector Search:** Indexes literature embeddings for context-aware Q&A and claims verification.
* **Automated Summarization:** Produces bulleted executive summaries, methodology overviews, and contribution lists.
